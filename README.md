## 技术要点

### 硬件资源（实验箱）
- **MCU**：AT89S52（8051 内核）
- **传感器**：DS18B20 温度传感器、HS1101 湿度传感器、ADC0809 模数转换（模拟电压采集）
- **执行器**：步进电机、DAC0832 数模转换→LED 亮度调节、有源蜂鸣器（PWM 调音）
- **显示**：LCD1602 字符液晶、八位 8 段数码管
- **输入**：矩阵键盘、八位轻触按键

### 控制算法
- **PID 控制**（题目 2、7）：比例 + 积分 + 微分闭环调节，含积分限幅防饱和
- **比例控制**（题目 3）：根据误差比例调节执行器输出

### 软件开发环境
- **IDE**：Keil μVision（C51 编译器）
- **编程语言**：C（ANSI C89 / C51 扩展）
- **仿真**：Proteus（.DSN 原理图仿真）
- **烧录**：通过 USB 烧录器写入 AT89S52 Flash

## 快速开始

1. 使用 Keil μVision 打开对应题目的 `.uvproj` 工程文件
2. 编译工程（Build）生成 `.hex` 文件
3. 在 Proteus 中打开 `.DSN` 仿真文件加载 hex，或通过烧录器将 hex 写入实验箱 MCU
4. 通过按键设定目标值，观察系统闭环调节过程
